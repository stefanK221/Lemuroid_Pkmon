> **状态定义**：✅ 已实现且有用户实测；🟡 已写代码/CI通过但当前修改未实机验收； ⬜ 待开发；⛔ 受前置条件阻塞。**CI 通过不等于实机通过。**
>
> 每次开发完成必须同时更新本文件、[变更记录](GBA_PLUS_CHANGELOG.md) 与 [问题复盘](GBA_PLUS_KNOWN_ISSUES.md)（如有新问题）；不得提前将待验证项标记为 ✅。
>
> 基线：开发分支 `feature/gba-plus-quick-tools`；稳定参考 `feature/gba-plus-foundation`。任何版本以**提交 SHA + Actions run + ROM SHA-256** 三者标识，不能只写“最新版”。

> **2026-10-16 用户变更：取消额外开发“全队完整经验共享”；使用游戏内现有学习装置。游戏原生学习装置不等同于全队每人获得100%经验。对应原生 EXP hook、调试开关及 ROM 分析不再列为发布阻塞项；历史代码保留但不作为可用游戏功能宣传。开发重点调整为领取指定精灵、仅队伍等级/性格编辑、穿墙、金手指及界面优化与实机验证。**

## 0. 已确认的用户约束（必须保留）
- Android 手机上直接运行 GBA 游戏，保留 Lemuroid 正常的显示、色彩和操作；金手指入口可点击。
- **优先直接读写当前游戏 SRAM/SAV**，不要要求用户手动导出 SAV 再导回；导入导出仅为可选备份。
- 默认**不清空存档、不覆盖已存在的盒中精灵、不修改未选中的队员**；修改前备份、危险操作二次确认。
- 六名队员可以分别设置 IV/EV；UI 显示名称/等级，**不向普通用户展示内部物种 ID**。
- **新增“编辑已有精灵”等功能只操作当前队伍（最多6只）**：显示队内顺序、名称、当前等级，用户明确选中队员后才可修改；不提供电脑盒精灵的编辑入口，不扫描/修改电脑盒内容。已有“领取新精灵到第一个空盒位”功能单独保留，绝不与队伍编辑混用。
- 仅适配已核验的《漆黑的魅影 5.0EX+BW》ROM；未知 ROM 哈希必须安全拒绝，而不是按文件名猜测。
- 同一套功能尽量集成到**一个 APK**，自动化验收后再让用户安装测试，避免频繁往返。
- **图鉴编号必须以该游戏内显示的图鉴编号为准**，不能混用全国图鉴号或内部存储 ID。未从该 ROM 建立并验证映射前不启用“图鉴编号领取”。

## 2. 下一阶段执行顺序

**当前合并交付范围（以用户最新决定为准）：**① 仅对当前队伍成员编辑等级1～100；② 仅对当前队伍成员编辑25种性格；③ 领取与图鉴编号、金手指及穿墙功能完善；④ 界面优化。全队经验共享开发已取消。**不编辑电脑盒中的已有精灵**；领取新精灵到空盒是原有独立功能。领取界面显示ROM图鉴可领取编号范围，输入编号后先显示中文名称并由用户确认。穿墙入口对用户统一命名为**“穿墙功能”**（不再展示“穿墙测试”字样），保留正常开启/关闭以及残留效果安全提示。三项开发、测试、打包成一个APK，必须先过自动化与存档安全回归再进入手机验证。

1. **P0 稳定性/发布基线**：对齐所有 CI 结果；金手指全部关闭、搜索排序不串码；升级覆盖安装、当前 SAV 备份/恢复、实机回归；不因功能开发牺牲已有稳定功能。
2. **P1 图鉴映射**：已解析该 ROM 中的物种→图鉴号表（411条唯一映射）；下一步对照游戏里实际显示的图鉴页面；未对上的编号不能标“游戏内验证通过”。仅针对已校验 ROM，从 ROM 解析“游戏内图鉴号 ↔ 物种内部 ID ↔ 中文名”，制作已知样本对照，错误/缺失映射禁止领取。
3. **P1 领取自定义等级及六项IV/EV**：基础代码已实现，等待包含图鉴编号、等级、性格、闪光、IV/EV 的同一 APK 编译，再统一“取出电脑盒→查看属性→保存重载”游戏内验证；性格与闪光旧版已有用户确认。
4. **P1 操作界面与验证**：快捷工具分区、明确开启状态、确认与备份提示；等级/性格、图鉴编号及穿墙实机回归。
5. **P2 技能、特性、PP、内置金手指库**：基于当前 ROM 表，逐项新增可回退实现。
6. **P3 低频扩展**：其它改版 ROM/华丽大赛数值等。

## 3. 每个功能的「完成」标准（DoD）

1. **需求**：界面入口、操作与关闭/撤销语义写清，说明适配 ROM 和限制。
2. **安全**：严格版本检查；不覆盖他人精灵或 SAV；修改前备份；异常时原存档保留。
3. **测试**：至少正常/边界/错误输入/关闭或重启/存档重载五类用例；有对应提交。
4. **CI**：APK 编译、相关自动测试和代码检查分别记下结论；失败不能被“APK 成功”掩盖。
5. **实机**：记录设备/系统、SHA、ROM 指纹、步骤、预期/实际结果；未经实测标 🟡。
6. **交付**：APK 下载链接、build SHA、SHA-256、覆盖安装及备份提醒；一版仅推荐一个经确认的 APK。
